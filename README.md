# AI个人形象四维分析图卡生成器

独立本地网页项目：上传一张照片，手动选择风格方向，生成四套可预览、可导出的形象参考长图。

## 项目定位

这是一个面向形象顾问、美业门店、私域运营的轻量 MVP。当前版本不调用云端模型，不上传客户照片，所有生成都在浏览器本地完成。

重要边界：当前是“规则化本地图卡模板”，不是照片真实诊断系统；它不会识别人脸、肤色、发质或五官比例。

## 四套交付

- 妆容分析
- 形象分析
- 发型分析
- 穿搭分析

## 功能

- 上传一张人像照片并本地预览
- 填写姓名/昵称、年龄段、主要场景
- 选择自然清透、清冷简约、甜美温柔、高级通勤四种风格方向
- 一键生成四套长图预览
- 单张导出 PNG
- 批量导出四张 PNG
- 桌面和手机宽度自适应预览

## 使用

```bash
cd ai-personal-image-card-generator
python3 -m http.server 5178
```

打开：

```text
http://127.0.0.1:5178
```

如果 5178 被占用，换一个端口即可：

```bash
python3 -m http.server 5180
```

然后打开：

```text
http://127.0.0.1:5180
```

测试示例入口：

```text
http://127.0.0.1:5178/?demo=1
```

## 当前版本边界

- 当前是本地半自动 MVP，不依赖后台和 API Key。
- 上传照片后，浏览器会根据“手动选择的风格方向 + 固定规则模板”生成四套结构化图卡，并支持导出 PNG。
- 分析内容为“AI形象风格参考”口径，不做医疗诊断或绝对审美判断。
- 后续可把 `app.js` 里的规则化文案替换为视觉大模型 API，保留现有图卡模板和导出能力。

## 隐私说明

- 默认不会把图片发到任何服务器。
- 浏览器只用 `FileReader` 读取本地文件并生成预览。
- 导出的 PNG 由本地 Canvas 生成。

## 交付 SOP

1. 上传清晰正脸照，避免遮挡、强滤镜、强逆光。
2. 选择客户主要使用场景和风格方向。
3. 点击“生成四套图卡”。
4. 逐张检查妆容、形象、发型、穿搭文案是否适合客户本人。
5. 必要时由顾问调整话术后再外发。
6. 导出 PNG，文件名格式为：`姓名_图卡类型_日期.png`。

发客户前检查：

- 不把模板结果说成绝对诊断。
- 不使用打击型表达。
- 不承诺变美效果。
- 涉及真实消费建议时，必须由顾问复核。
